# Capstone Project
**자율 주제로 AI 기반 서비스 완성하기**

- Python 기반 AI 활용, AI Agent 개발을 통해 쌓은 역량울 활용하여 AI 기반 서비스 구현
- 자율 주제 기반으로 생성형 AI와 AI agent를 활용한 서비스 기획 및 배포 수행
- API 호출
- 문제 정의 -> 서비스 설계 -> AI Agent/워크플로우 구축 -> 프론트엔드 연동 -> 배포 및 사용자 피드백 반영
- AI Native 서비스 개발 전 주기 경험

## 01. 최종 결과물
**1) 기획서**: 문제 정의, 타겟 사용자, AI 활용 방식, 기술적 접근 방식, 일정 계획을 포함한 프로젝트 기획서 작성

**2) 기능 요구 명세서**: 서비스의 기능 요구사항과 비기능 요구사항 정의, 시스템 아키텍처 설계

**3) AI 서비스**: 생성형 AI 또는 AI Agent를 핵심으로 활용하는 서비스 구현
     + 실제 사용자 테스트 및 피드백 반영

**4) Github 저장소**: 모든 소스 코드와 문서를 Github에 업로드, 버전 관리 및 기록

**5) 발표 자료**: 프로젝트 결과를 발표할 수 있는 자료 준비
   + 문제 정의 및 해결 과정
   + AI 활용 방식 및 기술적 의사결정 근거
   + 사용자 피드백 및 개선 사항

**6) 서비스 배포**: 외부에서 접근 가능한 형태로 서비스 배포 (무조건 필수)

## 02. 과제 목표
- 사용자의 문제 정의 및 AI 활용 해결방식 설계
- 생성형 AI API 또는 AI Agent를 서비스에 효과적으로 통합
- 프롬프트 엔지니어링, RAG, 메모리 관리 등 AI 활용 기법 학습
- 노코드 자동화 도구와 Python 조합의 서비스 구현
- 사용자 피드백 수집 및 서비스 개선

## 03. 기능 요구 사항
**1) 주제 선정**
- 자율 주제 선정 후, 아래 조건 충족 필수
- 생성형 AI 또는 AI Agent가 서비스의 핵심 기능으로 포함
- 실제 사용자(최소 5명 이상)에게 서비스를 제공하고 피드백 수집

**2) 필수 기술 요소 (아래 중 2개 이상 포함)**

| 기술 요소 | 설명 | 예시 |
|---|---|---|
| AI Agent | 사용자의 의도를 파악하고 도구를 활용하여 목표를 달성하는 Agent | 일정 관리 Agent, 정보 검색 Agent, 업무 자동하 Agent |
| RAG(검색 증강 생성) | 외부 지식을 검색하여 LLM 응답에 활용 | 문서 기반 Q&A, 지식 베이스 챗봇 |
| 멀티모달 AI | 텍스트, 이미지, 음성 등 다양한 형식의 입출력 처리 | 이미지 분석 서비스, 음성 기반 인터페이스 |
| 자동화 워크플로우 | 여러 서비스를 연동한 자동화 파이프라인 | 콘텐츠 자동 생성, 알림 자동화 |
| Long-term Memory | 사용자별 대화 기록 및 선호도를 저장 및 활용 | 개인화 추천, 맥락 유지 대화 |

**3) 팀 구성**
- 3~6인
- 팀원 간 역할 명확히 분담

**4) 프로젝트 수행**
- 해결하고자하는 문제 명확히 정의
- 서비스 아키텍처 설계 및 문서화
- AI 활용 방식(프롬프트, Agent 구조, RAG 등) 설계 및 문서화
- 프로젝트 진행 과정 문서화
  + README.md에 프로젝트 개요, 팀원 역할, 기술 스택, 실행 방법, 결과 정리
  + Git 활용 체계적인 버전 관리
- 외부에서 접근 가능한 형태로 서비스 배포
- 실사용자 테스트 진행 및 피드백 반영

**5) 개발 환경**
- 프로그래밍 언어, 프레임워크, AI 서비스는 자유롭게 선택
- 선택한 기술 스택의 선정 이유 문서화

**6) 제약 사항**
- 필수 요건
  / 생성형 AI 또는 AI Agent가 서비스의 핵심 기능으로 포함
  / 기능 요구 사항의 필수 기술 요소 중 2개 이상 포함
  / 서비스를 배포 및 실사용자 피드백 수집
  / Github를 통한 버전 관리 기록 필수
- AI 윤리
  / AI 생성 콘텐츠임을 사용자에게 명시
  / 개인정보 수집 시 동의받고 안전하게 관리
